# Planning history

These are the plan and design notes written before and during the event, under the project's working name **KitCheck**. They describe what we intended at the time: two foam cubes ("sensor", "motor"), LeRobot 0.4.1, an MI300X cloud GPU, an order page. Much of that changed once we had the real kit: three colored rings, LeRobot 0.6.2, an AMD Radeon AI PRO R9700 in AMD Cloud, and the station dashboard.

They're kept as an honest record of the design process. For the system as built, read the [top-level README](../../README.md); for what happened on the day, read the [day 1 lab log](../11-day1-log.md).

| File | What it was |
|---|---|
| `PLAN.md` | The original plan: idea, schedule, cuts, odds |
| `SPEC.md` | The scope rewrite on the night of day 1, when the project became RingSort |
| `00-architecture.md` … `10-voice.md` | One design doc per part, written before the event |
